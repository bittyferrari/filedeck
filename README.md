## Features

- **Enter** opens folders, files and apps; **Backspace** goes back; **F2** renames (just the name, not the extension)
- Real **cut & paste** with ⌘X / ⌘V — name clashes keep both, nothing is overwritten
- **Properties** window (⌥-double-click, ⌥Enter or ⌘I): size, contents count, dates, read-only / hidden / hide extension, default app
- **Address bar** you can type into: paths, `~/Downloads`, app names, URLs, `\\server\share` (SMB) — with Tab completion
- Tabs and windows, details and thumbnail views with Quick Look previews
- Right-click › New: text document, Markdown, RTF, HTML or an empty file; Create Shortcut (macOS aliases)
- Sidebar imports your Finder favorites; pin files and apps; eject buttons for external drives
- **22 themes** (Explorer, GitHub, Dracula, Nord, Tokyo Night, Catppuccin…) with light & dark versions, frosted glass, custom colors and JSON sharing
- 8 languages: English, 繁體中文, 简体中文, 日本語, 한국어, Deutsch, Français, Español

## Install

1. Download **FileDeck.dmg** and drag FileDeck into Applications.
2. Open it — it's signed with a Developer ID and notarized by Apple.
3. Allow folder access when macOS asks (or add FileDeck to *Full Disk Access*).

Requires **macOS 13 Ventura or later**, Apple silicon or Intel. Free — no ads, no tracking.
